GNOME Disks

Manage disk drives, mount partitions, benchmark drives, and create disk images.

Launch GNOME Disks

Documentation

GNOME Disks provides a simple interface to format, partition, and monitor disks. It can create and restore disk images, check SMART data, and benchmark drives.

Usage Examples

Execute gnome-disks to launch the GUI. Select a disk to view options.
